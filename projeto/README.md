# INSTRUÇÔES DE COMPLIAÇÂO E EXECUÇÂO
- No terminal do linux, wls, já que o arquivo Makefile foi criado, digite:
    - make clean
    - make all
    - make run
- No terminal pardrão(powershell do windows):
    - cd "caminho do projeto no seu PC"
    - gcc -I ./src/includes ./src/main2.c ./src/fatorial.c ./src/historico.c ./src/matriz.c ./src/estatistica.c ./src/menus.c  -o main2.exe
    - ./main2.exe
